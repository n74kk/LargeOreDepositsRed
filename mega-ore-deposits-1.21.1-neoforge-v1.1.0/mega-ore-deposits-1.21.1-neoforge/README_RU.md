# Mega Ore Deposits v1.1.0 (Minecraft 1.21.1 NeoForge)

Мод добавляет генерацию **крупных подземных месторождений руд**, **поверхностные камни-индикаторы** и **встроенную вкладку «Месторождения» прямо в меню создания мира** (рядом со стандартными вкладками *Игра / Мир / Ещё*).

## Что нового в v1.1.0
- **Вкладка «Месторождения» при создании мира (`CreateWorldScreen`)**:
  - **Крупные жилы (ВКЛ/ВЫКЛ)** — полностью включает или отключает мод для создаваемого мира;
  - **Индикаторы (ВКЛ/ВЫКЛ)** — управление спавном камней-образцов на поверхности;
  - **Размер жил (`0.25x .. 2.50x`)** — множитель радиуса эллипсоида;
  - **Плотность руды (`0.20x .. 2.00x`)** — насыщенность жилы рудными блоками;
  - **Частота жил (`0.25x .. 3.00x`)** — работает через кастомный `megaoredeposits:deposit_rarity`;
  - **Богатое ядро (`0.00x .. 2.50x`)** — шанс появления цельных блоков сырой руды в центре жилы;
  - **Макс. индикаторов (`0 .. 20`)** — лимит камней-образцов над одной жилой;
  - **Пресеты**: *Стандарт*, *Обильный*, *Редкие гиганты*, *Хардкор*;
  - **Сбросить по умолчанию** — возвращает значения из `config/megaoredeposits-common.toml`.
- **Сохранение настроек на каждый мир отдельно**: выбранные параметры записываются в `<папка_мира>/megaoredeposits-world.json` ещё до генерации стартовых чанков (`ServerAboutToStartEvent`) и автоматически загружаются при каждом повторном входе в этот мир.
- **Экран глобальных настроек**: в меню *Моды -> Mega Ore Deposits -> Настроить* работает встроенный экран конфигурации NeoForge.

## Сборка `.jar` файла
1. Установите **JDK 21** (например, Eclipse Temurin 21).
2. Распакуйте архив и откройте папку `mega-ore-deposits-1.21.1-neoforge` в **IntelliJ IDEA** (или запустите `gradle build` в терминале).
3. Выполните задачу `Tasks -> build -> build`.
4. Готовый мод появится в `build/libs/megaoredeposits-1.1.0.jar`.

## Быстрый тест в игре
1. Нажмите **Одиночная игра -> Создать новый мир** и перейдите на 4-ю вкладку **Месторождения**.
2. Выберите пресет (например, *Редкие гиганты* или *Обильный*) и создайте мир.
3. Проверьте файл `<папка_мира>/megaoredeposits-world.json` — в нём сохранятся все выбранные параметры.
4. Для мгновенного спавна жилы в Творчестве выполните:
   ```
   /place feature megaoredeposits:iron_deposit ~ ~-25 ~
   ```
